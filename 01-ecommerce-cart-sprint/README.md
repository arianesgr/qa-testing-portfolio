# 🧪 Sprint 01 – E-commerce Cart Testing

## 👩‍💻 Overview

This sprint simulates a real QA cycle performed in an Agile environment focused on validating the shopping cart functionality of an e-commerce application.

The objective was to execute functional testing, identify defects, and suggest improvements based on user experience and system behavior.



## 🎯 Sprint Goal

Ensure that the cart functionality behaves as expected across different user interactions, including adding, updating, and removing products.



## 📌 Scope

- Cart functionality validation
- Functional test case execution
- Defect identification and reporting
- Basic regression validation
- UX improvement suggestions



## 🔄 QA Process

- Requirement understanding
- Test case design
- Test execution
- Bug reporting
- Retesting validation
- Improvement recommendations



## 🧪 Deliverables

- Manual Test Cases
- Bug Reports
- Execution Results
- Improvement Suggestions
- Evidence (screenshots)



## 🧠 QA Mindset Applied

This sprint reflects a structured QA approach based on real industry practices including traceability, validation, and continuous improvement mindset.
